## 🔒 التحقق والأمان (Security & Integrity)

- جميع التحديثات وبيانات الإعدادات المباشرة موقعة رقمياً بتشفير **RSA-2048 / SHA-256**.
- يتم التحقق التلقائي من بصمة كل ملف قبل تشغيله أو تطبيقه.
- للتحقق اليدوي عبر PowerShell من بصمة المثبت:
```powershell
Get-FileHash -Path "IMEI_SCAN_PRO_Setup_x64.exe" -Algorithm SHA256
```
